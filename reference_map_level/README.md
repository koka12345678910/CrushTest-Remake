# reference_map_level — уровень для переноса в основной проект

Здесь только сам уровень и всё, что ему нужно: 2 сцены, 29 текстур, 2 шейдера, 3 скрипта, лицензии.
Сделан в Godot 4.7, нужен Godot 4.4 или новее (сцены формата 4, `TileMapLayer`).

## Как подключить

1. Скопируй папку `reference_map_level` целиком **в корень** проекта, чтобы получилось `res://reference_map_level/`.
   Пути внутри сцен рассчитаны ровно на это место. Если нужно положить её глубже, сначала положи в корень,
   а потом перетащи внутри Godot в панели «Файловая система»: так редактор сам поправит все ссылки.
   Через проводник Windows переносить нельзя — ссылки сломаются.
2. Открой проект. Godot импортирует текстуры (1–2 минуты). Настройки импорта лежат рядом в `.import`:
   атласы сжаты в BC7 («VRAM Compressed»). Не переключай их на Lossless: без сжатия карта займёт примерно в
   4 раза больше видеопамяти, и встроенной видеокарте её может не хватить.
3. Сцена уровня — `res://reference_map_level/reference_map.tscn`. Лагерь `ruined_camp.tscn` уже вставлен в неё
   (узел `Objects/RuinedCamp`), отдельно его подключать не нужно.

UID в файлах нет: Godot при первом открытии сам выдаст свои, поэтому с файлами твоего проекта ничего не пересечётся.

## Что внутри сцены

| Узел | Что это |
|---|---|
| `ReferenceMap` (Node2D) | корень; `texture_filter = Nearest` для всей карты |
| `Ground` … `Walls` (TileMapLayer) | земля, брусчатка, вода, обрывы, каньон, мосты; у слоёв масштаб 0.5 (текстуры двойной плотности) |
| `Objects` (y-sort) | дома, деревья, пропсы, руины и вставленный лагерь `RuinedCamp` |
| `Markers` (Marker2D) | `PlayerStart`, выходы `Exit_*` и игровые точки (NPC, Boss, LockedGate, сундуки и т.д.) |
| `Collision` (StaticBody2D) | вся коллизия карты: прямоугольники + полигоны воды; слой/маска 1 по умолчанию; узел скрыт, но работает |
| `SouthZones`, у лагеря `Triggers` | зоны-триггеры (Area2D) юга и лагеря |
| `Night` | `CanvasModulate` (ночь) и источники света: факелы, костры |
| `Atmosphere` | туман (`shaders/fog.gdshader`), частицы |
| `Grade` (CanvasLayer, layer 20) | экранная цветокоррекция (`shaders/grade.gdshader`), включается только в игре. Она лежит поверх всего, что ниже слоя 20, — если твой интерфейс на слое ниже 20, подними его выше или убери этот узел |

У лагеря есть свои `PreviewCamera` и ночь. Внутри этой карты они сами отключаются: камера и ночь работают,
только когда лагерь запущен отдельной сценой. Своей камеры у карты нет — используй камеру игрока.

## Выходы на новые локации

Грунтовые дороги уходят за край карты, маркеры стоят у самого края проходимой зоны. Сюда вешай `Area2D` перехода:

| Маркер | Куда ведёт | Позиция (x, y) |
|---|---|---|
| `Exit_W` | запад, главная дорога через ферму | -2928, 1068 |
| `Exit_NW` | северо-запад, над мельницей | -2928, 186 |
| `Exit_N2` | север, от западного квартала | -1645, -112 |
| `Exit_N` | север, старая дорога за часовней | -288, -112 |
| `Exit_SW` | юго-запад | -2928, 2020 |
| `Exit_S` | юг | -2066, 2160 |

## Координаты и тайлы

Позиции маркеров и узлов — обычные мировые пиксели. У тайловых слоёв масштаб 0.5, поэтому мировую точку в клетку
переводи так: `layer.local_to_map(layer.to_local(global_pos))`. Вызов `local_to_map(global_pos)` без `to_local`
даст неправильную клетку.

## Лицензии

`licenses/` — список источников ассетов (`CREDITS.md`) и лицензии паков. Главное: арт моста CraftPix можно
использовать в игре, но нельзя распространять как отдельные ассеты. Происхождение листов, присланных тобой
(лагерь, дома-руины, style sheet), в `CREDITS.md` отмечено как «уточнить перед релизом».
